# Hollow Knight theme for Eitr

A dark [Eitr](https://eitr.info) theme with Hollow Knight art: soul blue on Hallownest night, with 5 wallpapers.

![Preview](hollow-knight/preview.png)

## Install

Open the Eitr Store, choose Themes, and search for Hollow Knight.
